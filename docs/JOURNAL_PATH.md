# From repository to paper (suggested path)

1. Run the GrassClover benchmark and write the results into README section 5 and a `results/` folder.
2. Collect 60 or more paired quadrats with a partner trial; run the human-observer comparison.
3. Add a learned baseline and compare.
4. Write the manuscript from the README structure. Candidate venues to check for scope, fees and article type: *Computers and Electronics in Agriculture*, *Plant Methods*, *Grass and Forage Science*, *Smart Agricultural Technology*, or a CVPR/ICCV agriculture workshop for the dataset and benchmark angle. Check each journal's AI-use and data policies.
5. Deposit code and data with a DOI (Zenodo via GitHub release) before submission.
6. A short, honest email to a researcher works best with a repository link, one figure and one question about their data.
